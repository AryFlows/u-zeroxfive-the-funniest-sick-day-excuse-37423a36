One line, under 200 characters, that gets you out of work and gets a laugh.

> My neck locked up overnight so I can only nod yes, and HR says that counts as agreeing to everything, so I'm staying home.

**122 characters, 1 line.** A stiff neck is a reason a boss might half believe; the twist — nodding counts as agreeing to everything — lands near the end, in the voice of a real message to a boss.

Run: `node main.ts` writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR`).
